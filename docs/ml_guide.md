# 회귀 분석 · 머신러닝 안내

> 이 문서는 `analysis.py` 안의 설명에서 자동으로 만들어집니다. (`python analysis.py guide`)

## 1. 회귀 분석이란

표의 한 열(**예측할 열**)을 다른 열들(**설명하는 열**)로 맞혀 보는 일입니다. 예: 지역 · 면적 · 건축연수로 감정가를 예측.

| 이 프로그램에서 | 교과서 용어 | 뜻 |
| --- | --- | --- |
| 예측할 열 | 종속변수 · 목표변수 · y | 알고 싶은 결과. 숫자여야 합니다 |
| 설명하는 열 | 독립변수 · 설명변수 · 특성(feature) · X | 결과에 영향을 줄 것 같은 원인 후보 |
| 결정계수 R² | coefficient of determination | 예측이 실제 값의 오르내림을 얼마나 설명하나 (1 이면 완벽, 0 이면 평균만 찍는 수준) |
| 잔차 | residual | 실제 값 − 예측 값 |

**머신러닝(machine learning)** 은 아서 새뮤얼이 1959년 체커 프로그램을 설명하며 쓴 말로, 규칙을 사람이 적어 주는 대신 데이터에서 규칙을 찾게 하는 방법입니다. **딥러닝(deep learning)** 은 그중 신경망의 층을 깊게 쌓는 갈래입니다.

## 2. 다섯 단계

| 단계 | 하는 일 | 자동으로 해 주는 것 |
| --- | --- | --- |
| ① 변수 지정 | 예측할 열 하나, 설명하는 열 여러 개를 고름 | 숫자 열과 번호표 열을 가려 추천 |
| ② 정제 | 겹친 행 제거, 빈칸 채우기, 글자 열을 숫자로 | 중앙값 · 평균으로 채우기, 글자 열을 0/1 열로 펼치기 |
| ③ 이상 탐지 | 입력 실수 같은 이상한 행을 찾아 학습에서 뺌 | 다섯 가지 방법, 이유를 글로 표시 |
| ④ 모델 선택 | 9가지 중 하나를 고르거나 모두 비교 | 교차 검증으로 순위 매기기 |
| ⑤ 결과 · 그래프 | 정확도, 열 중요도, 그래프 4장, 엑셀로 내보내기 | 전부 |

[자동 분석] 은 ①~⑤ 를 한 번에 돌립니다: 변수 추천 → 중앙값으로 채움 → 종합 방식으로 이상 탐지 → 9개 모델 비교 → 1위 모델로 학습.

## 3. 모델 9가지

| 모델 | 영어 이름 | 계열 | 언제 |
| --- | --- | --- | --- |
| 선형 회귀 | Linear Regression | 머신러닝 | 먼저 돌려 보는 기준선. 결과를 말로 설명해야 하는 보고서. 관계가 곧은 선에 가까울 때. |
| 릿지 회귀 | Ridge Regression | 머신러닝 | 설명 열이 많거나 서로 비슷한 열(면적과 방 수처럼)이 섞여 있을 때. |
| 라쏘 회귀 | Lasso Regression | 머신러닝 | 열이 아주 많은데 그중 몇 개만 중요할 것 같을 때. 변수 선택을 겸하고 싶을 때. |
| 의사결정나무 | Decision Tree | 머신러닝 | 규칙을 그림으로 보여 주고 싶을 때. 혼자서는 데이터에 지나치게 맞춰지기 쉬워 아래 두 모델의 재료로 더 많이 씁니다. |
| 랜덤 포레스트 | Random Forest | 머신러닝 | 무엇을 쓸지 모를 때의 안전한 선택. 이상값과 굽은 관계에 강합니다. |
| 그레이디언트 부스팅 | Gradient Boosting | 머신러닝 | 정확도가 가장 중요할 때. 표 데이터 경진 대회의 단골 우승 모델입니다. |
| k-최근접 이웃 | k-Nearest Neighbors | 머신러닝 | '비슷한 물건 몇 건의 평균'이라는 설명이 필요할 때. 열이 많아지면 '가깝다'의 뜻이 흐려져 성능이 떨어집니다. |
| 서포트 벡터 회귀 | Support Vector Regression | 머신러닝 | 행 수가 수천 건 이하이고 관계가 매끄럽게 굽어 있을 때. 행이 많아지면 느려집니다. |
| 신경망 (다층 퍼셉트론) | Neural Network · Multi-Layer Perceptron | 딥러닝 | 행이 아주 많거나 이미지 · 글 · 소리처럼 표가 아닌 데이터. 작은 표에서는 나무 계열과 엇비슷하거나 뒤지는 일도 많고, 관계가 매끄러우면 앞서기도 합니다 — [자동 분석] 으로 직접 견주어 보세요. |

### 선형 회귀 (Linear Regression)

- **이름의 뜻**: regression 은 라틴어 regredi(되돌아가다)에서 왔습니다. 골턴이 1886년 '키가 아주 큰 부모의 자녀는 평균 쪽으로 되돌아간다'는 현상을 regression 이라 부른 것이 통계 용어가 됐습니다. linear 는 선(line)이라는 뜻입니다.
- **역사**: 계산법인 최소제곱법은 르장드르(1805)와 가우스(1809)가 천체 궤도를 구하려고 만들었고, 골턴(1886)과 피어슨 · 율(1890년대)이 지금의 회귀 분석으로 다듬었습니다. 가장 오래되고 가장 많이 쓰이는 모델입니다.
- **하는 일**: 설명하는 열마다 가중치(계수)를 곱해 더한 값으로 예측합니다. '면적이 1㎡ 늘면 감정가가 얼마 오른다'처럼 계수를 그대로 읽을 수 있습니다.
- **언제**: 먼저 돌려 보는 기준선. 결과를 말로 설명해야 하는 보고서. 관계가 곧은 선에 가까울 때.

### 릿지 회귀 (Ridge Regression)

- **이름의 뜻**: ridge 는 산등성이라는 뜻입니다. 호얼(Hoerl)이 1962년 반응 표면의 능선을 따라가는 'ridge analysis' 에서 쓰던 이름을 회귀에 가져왔습니다.
- **역사**: 호얼과 케너드가 1970년에 발표했습니다. 같은 생각은 수학에서 티호노프 정규화(1943)로 먼저 나왔습니다.
- **하는 일**: 선형 회귀에 '계수를 너무 키우지 말라'는 벌점(계수 제곱의 합)을 더합니다. 서로 닮은 열이 여럿 있어도 계수가 널뛰지 않습니다. 벌점의 세기는 교차 검증으로 자동으로 고릅니다.
- **언제**: 설명 열이 많거나 서로 비슷한 열(면적과 방 수처럼)이 섞여 있을 때.

### 라쏘 회귀 (Lasso Regression)

- **이름의 뜻**: Least Absolute Shrinkage and Selection Operator(절댓값을 가장 작게 줄이고 골라내는 연산)의 머리글자입니다. 올가미(lasso)라는 뜻도 겹쳐, 필요 없는 열을 올가미로 조여 없앤다는 느낌을 줍니다.
- **역사**: 팁시라니(Tibshirani)가 1996년에 발표했습니다.
- **하는 일**: 벌점을 계수의 절댓값 합으로 줍니다. 그러면 도움이 안 되는 열의 계수가 정확히 0 이 되어, 어떤 열이 쓸모 있는지 모델이 스스로 골라 줍니다.
- **언제**: 열이 아주 많은데 그중 몇 개만 중요할 것 같을 때. 변수 선택을 겸하고 싶을 때.

### 의사결정나무 (Decision Tree)

- **이름의 뜻**: 질문이 나뭇가지처럼 갈라져 내려가는 모양에서 온 이름입니다. 맨 위 질문이 뿌리, 마지막 답이 잎입니다.
- **역사**: 모건과 손퀴스트의 AID(1963)가 시작이고, 브라이먼 등이 1984년 CART 로 회귀까지 정리했습니다. 퀸란의 ID3(1986) · C4.5(1993)도 널리 쓰였습니다.
- **하는 일**: '면적이 84㎡ 이상인가?' 같은 예/아니오 질문을 되풀이해 행을 무리로 나누고, 무리의 평균으로 예측합니다. 굽은 관계와 열끼리 얽힌 효과를 저절로 잡습니다.
- **언제**: 규칙을 그림으로 보여 주고 싶을 때. 혼자서는 데이터에 지나치게 맞춰지기 쉬워 아래 두 모델의 재료로 더 많이 씁니다.

### 랜덤 포레스트 (Random Forest)

- **이름의 뜻**: 나무(tree)가 모이면 숲(forest)입니다. 나무마다 행과 열을 무작위(random)로 뽑아 주므로 random forest 입니다.
- **역사**: 틴 캄 호(Tin Kam Ho)가 1995년 '무작위 결정 숲'을 제안했고, 브라이먼이 자신의 배깅(1996)과 합쳐 2001년에 지금의 랜덤 포레스트를 발표했습니다.
- **하는 일**: 조금씩 다른 나무 수백 그루의 예측을 평균합니다. 나무 하나의 실수가 서로 지워져 안정적이고, 손볼 설정이 거의 없습니다.
- **언제**: 무엇을 쓸지 모를 때의 안전한 선택. 이상값과 굽은 관계에 강합니다.

### 그레이디언트 부스팅 (Gradient Boosting)

- **이름의 뜻**: boost 는 밀어 올린다는 뜻입니다. 약한 모델을 차례로 보태 성능을 끌어올립니다. gradient(기울기)는 오차가 가장 빨리 줄어드는 방향을 뜻합니다.
- **역사**: '약한 학습기를 모아 강하게 만들 수 있는가'라는 물음에 샤파이어가 1990년 답했고, 프로인트와 샤파이어의 AdaBoost(1995)를 거쳐 프리드먼이 1999~2001년 그레이디언트 부스팅으로 일반화했습니다. XGBoost(2014) · LightGBM(2017)이 그 후손입니다.
- **하는 일**: 작은 나무를 하나 만들고, 그 나무가 틀린 만큼을 다음 나무가 배우는 일을 수백 번 되풀이합니다. 표 모양 데이터에서는 지금도 가장 정확한 축에 듭니다.
- **언제**: 정확도가 가장 중요할 때. 표 데이터 경진 대회의 단골 우승 모델입니다.

### k-최근접 이웃 (k-Nearest Neighbors)

- **이름의 뜻**: nearest neighbors 는 가장 가까운 이웃, k 는 몇 명의 이웃을 볼지 정하는 숫자입니다.
- **역사**: 픽스와 호지스가 1951년 미 공군 보고서에서 제안했고, 커버와 하트가 1967년 성질을 증명했습니다.
- **하는 일**: 새 행과 가장 닮은 k개 행을 찾아 그 값들의 (거리로 가중한) 평균으로 예측합니다. 따로 배우는 과정이 없고 '비슷한 사례를 찾아본다'는 설명이 그대로 통합니다.
- **언제**: '비슷한 물건 몇 건의 평균'이라는 설명이 필요할 때. 열이 많아지면 '가깝다'의 뜻이 흐려져 성능이 떨어집니다.

### 서포트 벡터 회귀 (Support Vector Regression)

- **이름의 뜻**: support vector 는 경계를 떠받치는(support) 점(vector)이라는 뜻입니다. 모델을 정하는 것은 모든 행이 아니라 경계에 걸린 몇몇 행뿐입니다.
- **역사**: 바프닉과 체르보넨키스가 1960년대에 바탕을 만들었고, 1992년 커널 기법(보저 · 기용 · 바프닉), 1995년 소프트 마진(코르테스 · 바프닉)을 거쳐 1996년 드러커 등이 회귀용 SVR 을 발표했습니다.
- **하는 일**: 예측선 둘레에 '이 정도 오차는 봐준다'는 띠를 두르고, 띠 밖으로 나간 행만 벌점을 줍니다. 커널로 굽은 관계도 다룹니다.
- **언제**: 행 수가 수천 건 이하이고 관계가 매끄럽게 굽어 있을 때. 행이 많아지면 느려집니다.

### 신경망 (다층 퍼셉트론) (Neural Network · Multi-Layer Perceptron)

- **이름의 뜻**: neural network 는 뇌의 신경세포(neuron) 연결을 본떴다는 뜻이고, perceptron 은 perceive(알아차리다)에 기계 이름에 붙이던 -tron 을 더한 말입니다. 층을 깊게(deep) 쌓은 신경망을 배우는 일이 딥러닝입니다.
- **역사**: 매컬러와 피츠의 인공 뉴런(1943), 로젠블랫의 퍼셉트론(1958)으로 시작했습니다. 민스키와 페퍼트가 1969년 한계를 짚어 한동안 식었다가, 1986년 루멜하트 · 힌턴 · 윌리엄스의 역전파로 여러 층을 배울 수 있게 됐습니다. 2006년 힌턴의 심층 신뢰망과 2012년 AlexNet 뒤로 딥러닝 시대가 열렸습니다.
- **하는 일**: 입력에 가중치를 곱해 더하고 굽은 함수를 통과시키는 층을 여러 겹 쌓습니다. 여기서는 64 · 32개 뉴런의 두 층짜리 작은 신경망을 씁니다. 어떤 모양의 관계든 흉내 낼 수 있습니다.
- **언제**: 행이 아주 많거나 이미지 · 글 · 소리처럼 표가 아닌 데이터. 작은 표에서는 나무 계열과 엇비슷하거나 뒤지는 일도 많고, 관계가 매끄러우면 앞서기도 합니다 — [자동 분석] 으로 직접 견주어 보세요.

## 4. 이상 탐지 5가지

| 방법 | 설명 |
| --- | --- |
| 사분위수 범위 (IQR) | 값을 크기순으로 세웠을 때 가운데 절반이 차지하는 폭(IQR)의 몇 배 넘게 벗어난 값을 찾습니다. 터키(John Tukey)가 1977년 상자그림과 함께 널리 알린 방법으로, 계산이 단순하고 설명하기 쉽습니다. |
| 표준점수 (Z-score) | 평균에서 표준편차의 몇 배 떨어졌는지(z) 를 재서 3배 넘는 값을 찾습니다. 값이 종 모양으로 퍼져 있을 때 잘 맞고, 아주 큰 이상값이 평균과 표준편차를 끌어당기는 약점이 있습니다. |
| 고립 숲 (Isolation Forest) | 무작위로 칸을 나누다 보면 남다른 행은 금방 혼자 남는다(고립된다)는 점을 씁니다. 2008년 Liu · Ting · Zhou 가 발표했고, 여러 열을 함께 봐서 '각 값은 평범한데 조합이 이상한' 행도 찾습니다. |
| 모델 잔차 (예측과 크게 다른 행) | 랜덤 포레스트가 '그 행을 빼고' 배운 뒤 예측한 값과 실제 값을 견주어, 비율이 크게 어긋난 행을 찾습니다. 0 을 하나 더 넣은 입력 실수처럼 '다른 열에 비해 말이 안 되는 값'을 가장 잘 잡습니다. 대신 조금 느립니다. |
| 종합 (사분위수 + 모델 잔차) — 권장 | 값 하나가 범위를 크게 벗어난 행(사분위수)과 다른 열에 비해 말이 안 되는 행(모델 잔차)을 함께 찾습니다. 두 방법은 잡는 것이 서로 달라서, 합치면 입력 실수를 가장 빠짐없이 걸러 냅니다. |

이상하다고 표시된 행은 지워지지 않습니다. 학습에서만 빼고, 결과 표에 이유와 함께 남깁니다. 정말 틀린 값인지는 사람이 확인해야 합니다.
